# Tribe Payments

> Tribe Payments is a London, UK-based payments technology company and issuer/acquirer processor. It gives banks, acquirers and fintechs a modular, API-driven platform - built around its ISAAC processing engine - to launch card and payment products without building core processing in-house. Coverage spans card issuing, merchant acquiring, a payment gateway, POS/SoftPOS terminal management, tokenization, fraud and risk monitoring, 3D Secure, Open Banking (PSD2 AIS/PIS) and Bank Connect / Banking-as-a-Service. Certified PCI DSS Level 1, ISO 27001, GDPR and PSD2 compliant; direct Principal Member of Visa, Mastercard and American Express.

## APIs

- [Payment Gateway - Credit Card API (v3)](https://doc.tribepayments.com/docs/trb-gateway--credit-card-api--v3): ECOM card sale, authorize, capture, refund, void, 3DS.
- [Payment Gateway - Hosted Payments API / HPP (v3)](https://doc.tribepayments.com/docs/trb-gateway--hosted-payments-api--v3): Tribe-hosted checkout that offloads PCI scope.
- [Payment Gateway - Credit Card Token API (v3)](https://doc.tribepayments.com/docs/trb-gateway--credit-card-token-api--v3): Card tokenization for card-on-file / recurring.
- [Payment Gateway - Reports API (v3)](https://doc.tribepayments.com/docs/trb-gateway--report-api--v3): Transaction reporting and reconciliation.
- [Point of Sale - Device Directory API (v3)](https://doc.tribepayments.com/docs/point-of-sale--device-directory-api--v3): Register and manage physical / SoftPOS terminals.
- [Risk Monitor - Client API (v1.1)](https://doc.tribepayments.com/): Real-time fraud and transaction-risk monitoring.
- [Open Banking - Bank API (v2)](https://doc.tribepayments.com/): Bank/ASPSP side of the Open Banking product.
- [Open Banking - TPP API (v2)](https://doc.tribepayments.com/): Third-party AIS/PIS account information and account-to-account payment initiation.
- [Issuer Processor - Program Manager API (v1.2)](https://doc.tribepayments.com/docs/issuing--program-manager-api--v1.2): Card issuing and program/cardholder management on ISAAC.
- [Issuer Processor - Transaction Authorization Interface (v1.2)](https://doc.tribepayments.com/docs/issuing--transaction-authorization-interface--v1.2): Card-transaction status webhooks to issuers.
- [Acquiring Processor - Acquirer API (v1)](https://doc.tribepayments.com/docs/acquiring--acquirer-api--v1): Acquirer-side transaction processing and settlement.
- [Acquiring Processor - Merchant API (v1)](https://doc.tribepayments.com/docs/acquiring--merchant-api--v1): Merchant onboarding and management.
- [Acquiring Processor - Terminal API (v2)](https://doc.tribepayments.com/docs/acquiring--terminal-api--v2): Physical terminal integration.
- [Acquiring Processor - Tokenization API (v1)](https://doc.tribepayments.com/docs/acquiring--tokenization-api--v1): Acquiring-side card tokenization.
- [Bank Connect - Payment Services API (v1)](https://doc.tribepayments.com/docs/bank-connect--payment-services-api--v1): Embedded banking / Banking-as-a-Service.
